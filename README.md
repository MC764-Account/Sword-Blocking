<h1>Sword Blocking</h1>

Let your sword block damage like a shield — just like in Minecraft before version 15w33c.
## Description

This mod brings back the classic sword blocking mechanic from before Minecraft 1.9.

No shield required. Simply hold any sword, right-click to raise it, and block incoming attacks from the front to reduce damage — just as you remember from the old versions.
## Features

Supports all sword types (Wooden, Stone, Iron, Gold, Diamond, Netherite) for blocking
Default right-click triggers blocking, consistent with shield usage and no conflict
Reduces incoming damage by 50% while blocking
Retains the original blocking sound and animation effects
Supports multiplayer servers (server-side installation required)

## Compatibility

Minecraft versions: 26.1.x ~ 26.2 
_(Support for 1.21 and above will be added later)_

## Installation

Download the .jar file of this mod
Place it into your mods folder
Launch the game, hold any sword, and long-press the right mouse button to block in the world
